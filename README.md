# MiniTransport
Manage a public transportation company of a city

Future-Feature Ideas:

Data for Insights module, using SQLite with discrete updates to clients, XCharts for visuals.
Buying more detailed, market data periodically from Data Agencies (Insight capability progression). Also able to sell the user data (legal or non-legal).
Tax Fraud, user has the freedom to not log spendings fully, and to not pay taxes.
Deal offers coming periodically from organizations, e.g. money laundry (besli cete misali garantili anlasmalar).
Company inspections: rates the company, charges the company if not up-to regulation. Shares the stats online, affects employment.
